# v2 release notes

Follow-up: [PCB first-paint correction](v2-pcb-first-paint.md) replaces incremental visible-tile publication with atomic viewport artwork before UI entrance, preserving belowfold preparation.

## Portfolio and case studies

- Expanded the portfolio with database-backed case studies for Delivery Intelligence, Leads Management, and Horecah. The studies use validated, versioned layout documents rendered by shared components; unavailable or invalid CMS data does not fall back to a hardcoded public case study.
- Refined project stories, metrics, role descriptions, and feature scope to distinguish lead activities from leads, clarify notification and delivery outcomes, and keep Horecah's contribution focused on payment and notification work.
- Project cards now choose “View Case Study” from the CMS availability flag, otherwise linking to an active project website. Retired websites have no website action while their published case study remains accessible.
- Added project-owned case-study background handling. The promoted CMS asset pair is a semantic SVG plus a spatial lens SVG stored with the project document in Supabase Storage; generic renderers use the validated document for content, diagrams, and responsive variants.
- Updated selected-work presentation and responsive case-study layouts, including structured evidence and impact sections, project diagrams, navigation back to Work, and readability treatments over exposed circuit artwork.
- Added site metadata, Open Graph artwork, browser and Apple icons, and an installable web app manifest.

## Circuit artwork and interaction

- Split the public PCB composition into three owners: static vector artwork, desktop native-SVG interaction, and touch Canvas interaction. The PCG-authored source geometry remains authoritative and unchanged in topology; desktop appearance and native scrolling/zoom behavior are preserved.
- Touch interaction now prepares bounded geometry regions, paints the glow and trails on Canvas, tracks contact and horizontal dragging through native vertical scroll, then holds at the final position for six seconds before fading. Static SVG tiles are snapshotted into device-density Canvas surfaces for touch composition, with SVG fallback if snapshotting fails.
- Restricted PCB diagnostics and the touch capture endpoint to development. Added spatial asset delivery and rendering preparation tools for bounded geometry and artwork validation.
- Refined shared header/footer behavior and circuit trails across page sections. The scrolled header uses a consistent blur treatment; footer trails follow section color bands and preserve the Contact glow at overlaps. EDD's Additional impact section has its own blue and pink palette treatment.
- Current evidence covers renderer interaction checks, geometry and asset validation, TypeScript, LAN asset delivery, desktop/laptop/mobile composition, and touch behavior. A slight softness when zooming the canvas snapshot on iPad was accepted. These checks do not establish an overall speedup; all four regenerated compositions were approved for this release and the three project pairs were remotely verified.

## CMS, delivery, and workflow

- Added Supabase project case-study schema, migrations, seeds, anonymous cached public reads, admin editing support, and cache invalidation after project mutations. Public case-study routes remain database-only and require a published project, its availability flag, and a valid document.
- Added a fail-closed pre-push check for unverified CMS promotion status so code cannot be pushed while required database and Storage ownership checks remain incomplete.
- Updated agent guidance and routing tools with separate model and reasoning-effort decisions, scoped context loading, lifecycle/memory checks, and evidence-based reassessment. The current project routing policy allows GPT-6.1 Sol and GPT-6 Luna; the evaluator records decisions but does not prove protected runtime interception or savings.
- Updated setup and operating documentation for LAN origins, build/dev single-writer handling, CMS ownership, and verification boundaries.
